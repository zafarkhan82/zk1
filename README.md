# zafar.de – Website Redesign

Moderne Mehrseiten-Website mit Einstiegsseite und vier Themen-One-Pagern.

## Struktur

| Seite | Beschreibung |
|---|---|
| `index.html` | Einstiegsseite mit vier interaktiven Theme-Karten |
| `politik-offenbach.html` | Politik in Offenbach |
| `smart-solutions.html` | ZK Smartpole & Smart Solutions |
| `fussball-jugend.html` | Fußball Jugend |
| `ahmadiyya-projekte.html` | Ahmadiyya Muslim Jamaat Projekte |

## Lokal starten

```bash
npx serve .
```

Dann im Browser `http://localhost:3000` öffnen.

## Deployment

Statische HTML/CSS/JS-Dateien – kann auf jedem Webhosting, GitHub Pages oder Netlify deployed werden.
